# 增量计划 v2（站点恢复后）

> 基线：2026-11-19。站点已从 Vercel 402 迁到 **Render + Cloudflare Worker**，
> 但当前 TTFB 3–10 秒，GSC 授权仍过期。计划顺序因此改变：**先性能与测量，再内容与增长**。

## 一、和 v1 相比变了什么

| 项目 | v1 | 现在 |
|---|---|---|
| 托管 | Vercel | Render 免费 + Cloudflare Worker |
| 停机 | 无 | 11/14–11/16 约 3 天 402 |
| TTFB | 未测 | **3–10 秒**（中位 9.8s，`perf:check` 失败） |
| GSC 数据 | 可用 | token 过期，11/09 后断档 |
| 索引 | 507 discovered | 停机后需重新确认 |
| Bing | 25 条已提交 | 停机期间可能抓取失败，需复查 |

## 二、优先级（按阻塞程度）

### P0：性能与稳定性（第 1–7 天）

没有这一层，内容/外链的收益都会被 CWV 和抓取预算吃掉。

- [x] 二选一：
  - **Render Starter $7/月**（常驻、CPU 更好），或
  - **Worker 边缘缓存 HTML**（免费，5–10 分钟 TTL，跳过 query 和 sitemap/robots）
- [x] `npm run perf:check` 中位 TTFB < **1.5s**（实测 977ms）
- [ ] 确认 Worker 的 keep-alive 每 14 分钟一次，Render 不睡眠
- [ ] 检查 5xx/冷启动告警（仓库已有 15 分钟 uptime check）

### P1：测量与索引恢复（第 3–14 天）

- [ ] 重新授权 GSC：`npm run gsc:auth`，并把 OAuth 应用发布到 Production
- [ ] 补拉 11/09–11/19 数据，量化 3 天停机的点击/曝光损失
- [ ] GSC 重新提交 sitemap；检查“网页”报告是否新增 5xx/抓取错误
- [ ] Bing 检查 Sitemaps 错误；如停机期间报错，重新提交 25 条优先 URL
- [ ] 请求索引 25 条 pending（每天 10–15）

### P2：内容深度（第 15–45 天）

- 每周 3 个已有页面，不新增页面
- 优先：hidden-object 集群、2-player、brainrot
- hidden-object 排名目标：56.8 → 45
- 新页索引率目标：35% → 45%

### P3：外链与放大（第 46–90 天）

- 每周 5 个真实外链，累计 20 个域名
- Bing 下一批 50 页（仅在索引率 ≥ 50% 后）
- 1 万访问/月后申请 Ezoic

## 三、修订后的 90 天目标

| 指标 | 现在 | 30 天 | 60 天 | 90 天 |
|---|---|---|---|---|
| TTFB 中位 | 9.8s | **<1.5s** | <1.2s | <1s |
| Google 28 天点击 | 234（停机前） | 200 | 350 | **500** |
| Google 28 天曝光 | 10.3K | 9K | 15K | **22K** |
| hidden-object 排名 | 56.8 | 52 | 45 | **40** |
| Bing 28 天曝光 | 7 | 50 | 300 | **600** |
| 新页索引率 | 25.7% | 35% | 45% | **55%** |
| 外链域名 | ~0 | 3 | 10 | **20** |

> 目标比 v1 下调，因为 3 天停机和 10 秒 TTFB 会先吃掉一部分恢复空间。

## 四、每周节奏

| 时间 | 动作 |
|---|---|
| 每天 09:00 | 日报（GSC/GA4） |
| 每天 09:10 | Bing 提交（有新增才发） |
| 周一 09:00 | `seo:cycle` + 性能检查 `perf:check` |
| 周三 10:00 | 改 3 个已有页面 |
| 周五 10:00 | 外链 5 封 + 周复盘 |

## 五、停止条件

| 信号 | 动作 |
|---|---|
| TTFB 中位连续 3 天 >3s | 暂停内容，先升 Render Starter 或加边缘缓存 |
| GSC 出现 5xx 抓取错误 | 回滚最近部署，查 Render 日志 |
| 新页索引率 <40% 两周 | 停止新增，先修内容与内链 |
| Bing 索引 <30% 四周 | 暂停提交，查页面质量 |

## 六、本周就做的 5 件事

1. 解决 TTFB（Render Starter 或 Worker 缓存）
2. GSC 重新授权并补数据
3. 重新提交 sitemap，查抓取错误
4. Bing 复查错误，必要时重提 25 条
5. 周三照常改 3 个页面
