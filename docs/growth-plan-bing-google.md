> 基线：2026-11-10。数据来自 GSC 28 天导出、Bing Webmaster、GA4。
> 原则：先修复索引与点击率，再做集群深度，最后做外链；不靠批量薄页冲量。

## 三、三个阶段

### 阶段 1：修复与测量（第 1–14 天）

**目标**：让已有页面被正确索引，先拿回点击率。

- [x] Bing API key 配置，25 条优先 URL 分批提交（10/天）
- [ ] GSC 请求索引 25 条 pending，每天 10–15 条
- [ ] 监控 wash arcade（240 曝光 / 1 点击）标题改动后的 CTR
- [ ] chess-royale（49 曝光 / 0 点击 / 排名 5.6）做一次摘要 A/B
- [ ] 18 个有曝光的新页补内链：类目页、指南、collection 各链一次
- [ ] AdSense 自查后**只申请一次**
- [ ] 确认 Bing Sitemaps 错误数保持 0

**通过标准**：Bing 索引 ≥ 10 个优先页；Google 点击回到 10–15/天。

### 阶段 2：集群深度（第 15–45 天）

**目标**：不是加页面数量，是把 5 个集群做深。

| 集群 | 动作 | 目标 |
|---|---|---|
| hidden-object | 补 10 个 curated 游戏、2 篇指南、3 条 FAQ、加内链 | 排名 56.8 → 45 |
| 2-player | 补 8 个 curated、1 个 collection、1 篇指南 | 拿到 100+ 曝光/月 |
| brainrot | 补 6 个 curated、短视频素材 | Bing 先起量 |
| car / racing | 各补 6 个 curated，强化 collection | CTR ≥ 3% |
| tower-defense | 182 曝光 / 0 点击 / 排名 65，重写导语 | 排名进前 50 |

**硬约束**：

- 每周新增 curated 页面 ≤ 15 个
- 不做全站 sitemap 大改
- 未 curated 页面继续 noindex，不放开

**通过标准**：新页索引率 ≥ 45%；hidden-object 排名 ≤ 45。

### 阶段 3：权威与放大（第 46–90 天）

**目标**：外链 + Bing 扩量 + 变现升级。

- **外链**：每周 5 个真实相关链接，累计 20 个域名
  - 游戏开发者、HTML5 目录、独立游戏博客、Reddit/Discord 社区
  - 不买链接，不做站群
- **Bing**：优先 25 条完成后，再按 10/天提交下一批 50 个 curated 页面
- **变现**：流量到 1 万访问/月申请 Ezoic；AdSense 先做主力
- **内容**：只做“有搜索需求”的集群，不再全类目铺

**通过标准**：Google 28 天点击 ≥ 600；Bing 28 天点击 ≥ 40；外链域名 ≥ 20。

## 四、每周节奏

| 时间 | 动作 | 耗时 |
|---|---|---|
| 每天 09:00 | 自动日报（GSC/GA4） | 0 |
| 每天 09:10 | Bing 提交 10 条优先 URL | 0 |
| 周一 | `seo:cycle` + 周报 + 索引审计 | 30 分钟 |
| 周三 | 补 2–3 个 curated 页面 + 内链 | 2 小时 |
| 周五 | 发 5 封外链邮件 + 看 Bing/Google 排名 | 1 小时 |
| 每月 1 号 | 复核目标、决定是否扩量 | 1 小时 |

## 五、停止/回滚条件

| 信号 | 动作 |
|---|---|
| 新页索引率连续 2 周 < 40% | 停止新增页面，先修内容与内链 |
| Bing 提交后 4 周索引 < 30% | 暂停 Bing 提交，检查页面质量 |
| Google 点击连续 2 周下跌 > 30% | 回滚最近一次模板/标题改动 |
| AdSense 连续被拒 2 次 | 停止申请，等流量到 1 万/月再走 Ezoic |
| 外链 8 周 < 5 个 | 停止内容投入，先解决分发 |
